# Open-source Rust contribution

Make a scoped open-source Rust contribution following the target project's contribution guidelines. Start by reproducing an issue or identifying a documentation gap, prepare a minimal patch, and record the evidence a reviewer needs.

## Contents

1. [Worked example](#1-worked-example)
2. [Design check](#2-design-check)

## 1. Worked example

```text
read CONTRIBUTING and recent changes → reproduce locally → design minimal fix → run required checks → prepare proposed change and rationale
```

## 2. Design check

Follow the project's issue and review process. Keep unrelated format changes out of a targeted patch.

## Acceptance criteria

- Produce a reproducible issue description or documentation gap.
- Provide a focused local patch with relevant checks and reviewer notes.
- Follow up on maintainers' feedback if you submit it.
