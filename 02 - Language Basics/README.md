# Rust Language Basics

This section covers the core language features needed to read, write, and understand Rust programs. The topics build on the introductory lessons and provide the foundation for ownership, collections, error handling, and larger projects.

## Learning roadmap

1. **Variables and mutability**
   - Bind values with `let`, understand immutable defaults, use `mut`, and learn shadowing.

2. **Data types**
   - Work with scalar types such as integers, floating-point numbers, booleans, and characters.
   - Use compound types such as tuples and arrays.

3. **Functions and expressions**
   - Define functions, pass parameters, return values, and distinguish statements from expressions.

4. **Comments and documentation**
   - Write regular comments and documentation comments that explain code clearly.

5. **Control flow**
   - Make decisions with `if` and repeat work with `loop`, `while`, and `for`.

6. **Scope and basic memory behavior**
   - Understand when variables are available and how values behave when a scope ends.

## Lesson format

Each topic in this section will use the same structure:

1. Concept and syntax
2. Small runnable example
3. Expected terminal output
4. Explanation of each important line
5. Practice ideas and common mistakes
